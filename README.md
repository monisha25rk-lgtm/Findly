# Foundly

Foundly is a client-side lost-and-found reporting form. Submit a lost or found
item to compare it with reports of the opposite type saved in the same browser.
Potential matches are ranked by similarity across item name, category, color,
and description.

Reports are stored in the browser's local storage; they are not sent to a
server and are not shared across browsers or devices. Open `index.html` in a
browser to use the app.
