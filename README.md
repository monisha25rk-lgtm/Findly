# Findly

A lightweight lost-and-found board built with plain HTML, CSS, and JavaScript.

## Run locally

Open `index.html` in a browser. No build step or server is required.

## Item listings

The community board starts with sample lost and found reports. Search across item names, descriptions, colors, categories, and locations; narrow results by report type or category. Submitting the report form adds the item to the board and saves the listings in the browser's `localStorage` under `findly-listings`.

Sample item photos load from Unsplash when online. If a photo cannot be loaded, the card displays a locally generated illustration instead.
