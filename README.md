# Foundly

Foundly is a client-side lost-and-found app. Browse sample lost and found item
cards, search by keyword, and filter by category. Submit a lost or found report
to add it to the listings and compare it with reports of the opposite type.
Potential matches are ranked by similarity across item name, category, color,
and description.

Sample and submitted reports are stored in the browser's local storage; they
are not sent to a server and are not shared across browsers or devices. Found
reports require a contact email, which is shown on the listing so someone who
lost the item can email the finder. Lost reports may include an optional email.
Remove a listing when an item has been returned; removal is saved in that browser.
Since the app uses local storage, listings and contact links are only available
in the same browser; sample contact links use reserved example.com addresses.
Open `index.html` in a browser to use the app.
